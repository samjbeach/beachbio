MVA pathway — minimal flux model

A stripped-down, MVP version of the BSF carotenoid flux tool — just the mevalonate trunk, as a real Jupyter notebook that runs entirely in your browser. Edit the parameters, re-run, and watch the pathway respond. No install, no server: Python is compiled to WebAssembly and executed client-side (JupyterLite + Pyodide).

acetyl-CoA → HMG-CoA → mevalonate → IPP ⇌ DMAPP → GPP → FPP HMGR MVK·PMK·MVD IDI FPPS FPPS

Open the notebook →

First load pulls the Python runtime (numpy / scipy / matplotlib) from a CDN — give it a few seconds, then it's cached. Run the cells top to bottom with Shift+Enter.

This is deliberately the minimal skeleton: seven pools, six reactions, solved to steady state with a small dilution term on every pool. Everything the full tool adds — shared cofactor pools, MVK product inhibition, expression cassettes, the carotenoid tail, and the Monte-Carlo sensitivity ensemble — is left out on purpose. Units are relative, not µM: the point is where flux backs up, not a calibrated titre.

Prefer to run it elsewhere? The notebook source is mva-flux-model.ipynb — download and open it in any Jupyter environment.
