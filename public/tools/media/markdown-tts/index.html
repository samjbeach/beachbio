How the key is handled. This is a static site with no server, so a GitHub Actions secret can't be read by the page — those secrets only exist during CI builds, never in the browser. Instead the key is entered here and kept in your browser's localStorage. That's fine because /tools/* is already behind Cloudflare Access (only you can reach it). The request goes straight from your browser to OpenRouter over HTTPS.

Length limits. Most TTS models cap input at a few thousand characters (OpenAI ≈ 4096). Very long documents may be rejected — split them if a request fails.
