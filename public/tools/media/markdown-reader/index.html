Markdown Reader (Kokoro)

Renders a Markdown file and reads it aloud with the Kokoro TTS model running entirely in your browser — no server, no API key. The current sentence and word highlight along with the audio.

3Reader

↓ download WAV
Runs on your device. The Kokoro model is downloaded from Hugging Face on first use and cached; synthesis then happens locally — the text never leaves the browser. Firefox / Windows uses WebGPU (fast). Firefox / Android has no WebGPU yet, so it falls back to WASM (CPU): it works and sounds identical, but is slower — read a section at a time rather than a huge document. Highlighting is exact at the sentence level; the per-word position within a sentence is estimated from that sentence's duration.
